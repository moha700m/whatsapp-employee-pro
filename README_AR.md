# موظف واتساب الذكي — AI WhatsApp Employee

برنامج سطح مكتب لويندوز 10 بواجهة عربية (من اليمين لليسار) يحلل محادثات العملاء وينظمهم ويقترح ردوداً باللهجة السعودية.
فيه وضعين: **اقتراح** (تعتمد الرد وتنسخه وترسله بنفسك) و**رد تلقائي** على كل العملاء في WhatsApp Web (مقفل افتراضياً، وتفعّله بنفسك من الإعدادات).

## صفحة «⚙️ سير عمل البوت»
أول صفحة في القائمة، ومنها تعدّل كل شي يتحكم بالرد التلقائي، والتعديل ينطبق فوراً بدون إعادة تشغيل:
- **عام**: المفتاح الرئيسي، والمزود (offline أو chatgpt_web)، وتجاهل المجموعات، وأوقات العمل مع رسالة خارج الدوام.
- **معلومات النشاط**: الاسم والوصف والموقع والأوقات، وجدول المنتجات والأسعار (إضافة وتعديل وحذف)، والأسئلة الشائعة (`سؤال | جواب`).
- **القواعد**: قائمة مرتبة. كل قاعدة فيها شرط (كلمات، تصنيف، سؤال سعر، سعر غير معروف، تحية، إيقاف، شكوى أو طلب موظف، سؤال شائع، أي رسالة) وإجراء (رد بقالب، رد مؤقت مع تنبيه، إيقاف الرد، تعيين تصنيف، رد ذكي، تجاهل). تقدر تضيف وتعدّل وتحذف وترتّب وتفعّل أو توقف أي قاعدة. القواعد الافتراضية هي نفس سلوك البرنامج السابق.
- **القوالب والأسلوب**: الترحيب، والرد المؤقت، وخارج الدوام، وتأكيد الإيقاف، والرد الاحتياطي، واللهجة، وأقصى طول، والإيموجي.
- **تعليمات ChatGPT**: نص التعليمات مع زر استرجاع الافتراضي.
- **التوقيت والأمان**: التأخير، وسرعة الكتابة، والفاصل، والحدود بالساعة، وكلمات الإيقاف.
- **🧪 تجربة**: الصق رسالة وشوف أي قاعدة تنطبق والرد بالضبط، بدون أي إرسال.
- **استيراد/تصدير** ملف JSON، وإرجاع الافتراضي. الاستيراد ما يشغّل الرد التلقائي أبداً.

## تشغيل الرد التلقائي (أول مرة)
1. شغّل `START.bat`. يثبت المتطلبات ويستخدم Google Chrome المثبت عندك (وإذا ما لقاه ينزّل Chromium تلقائياً).
2. افتح صفحة **الموظف الذكي** واضغط **🌐 فتح واتساب**. تنفتح نافذة Chrome خاصة بالبرنامج (ملفها في `data\chrome-profile`).
3. امسح رمز QR من جوالك (واتساب ← الأجهزة المرتبطة). تسويها مرة وحدة بس.
4. **الإعدادات**: عبّ معلومات النشاط والأسعار المعتمدة.
5. (اختياري) لو تبي الردود من ChatGPT: في نفس نافذة Chrome افتح تبويب chatgpt.com وسجّل دخولك بنفسك، وبعدها اختر المزود `chatgpt_web`. لو فشل أو تأخر، يرجع للمحلل المحلي تلقائياً.
6. فعّل **«تفعيل الرد التلقائي على العملاء»** واضبط التأخير والحدود، ثم احفظ.
7. ارجع لصفحة **الموظف الذكي** واضغط **▶ Start Employee**. للإيقاف اضغط **■ Stop** أو **⛔ الإيقاف الفوري**.

### الحمايات المدمجة
- تأخير عشوائي قبل كل رد (8–25 ثانية افتراضياً) وكتابة حرف بحرف مثل الإنسان.
- فاصل بين الردود في نفس المحادثة، وحد للردود في كل محادثة بالساعة، وحد كلي بالساعة.
- ما يرد مرتين على نفس الرسالة، ويتجاهل المجموعات افتراضياً.
- الشكاوى وطلبات التواصل مع موظف والأسعار غير المعروفة: يرسل مرة وحدة «أبشر، بيتواصل معك الزميل المختص قريب» ويحط العميل في قائمة **⚠️ يحتاجونك**.
- لو كتب العميل «لا ترسل» أو «وقف» (أو أي كلمة تضيفها) يوقف الرد عليه نهائياً.
- كل رسالة تنرسل تنسجل في سجل العمليات، وبيانات العميل تتحدث في CRM.
- ملاحظة: الرد الآلي الكثيف ممكن يعرّض رقمك للحظر من واتساب. خلّ الحدود معقولة، ويفضّل تستخدم رقم واتساب أعمال.

## التحديث
فك ضغط النسخة الجديدة فوق المجلد القديم. مجلد `data` (قاعدة البيانات وجلسة Chrome) مو داخل الملف المضغوط، فبياناتك تبقى زي ما هي.

## كيف يعرف إنه متصل؟ وكيف يقرأ؟
- **الاتصال**: البرنامج يفتح نافذة Chrome خاصة فيه على WhatsApp Web، وكل ثانيتين يشوف الصفحة: إذا ظهر رمز QR تكون الحالة «بانتظار مسح QR»، وإذا ظهرت قائمة المحادثات تكون «متصل». الحالة تظهر دائماً في الشريط العلوي.
- **القراءة**: كل كم ثانية يدوّر على المحادثات اللي عليها علامة «غير مقروءة»، ويفتحها، ويقرأ نص الرسائل الظاهرة على الشاشة (بدون API وبدون Cookies)، وبعدها يقرر الرد من القواعد أو الذكاء الاصطناعي ويكتبه.

## إذا ما اشتغل
- شغّل `DIAGNOSE.bat`. يطلع ملف `diagnose.txt` فيه كل التفاصيل، أرسله لنا.
- سجل التشغيل موجود في `data\logs\startup.log`.
- أول تشغيل تبقى النافذة السوداء مفتوحة عشان يبان أي خطأ.
- إذا ما انفتحت نافذة البرنامج (WebView2)، تنفتح الواجهة تلقائياً في المتصفح على عنوان محلي.

## طريقة التشغيل
1. ثبّت Python 3.12 من python.org (فعّل خيار "Add to PATH").
2. فك ضغط المجلد في أي مكان.
3. اضغط مرتين على `START.bat`. يدوّر على Python، وينشئ `.venv`، ويثبت المتطلبات (أول مرة تاخذ دقايق)، ويتأكد من وجود Chrome، وبعدها يفتح البرنامج بواجهة حديثة (نافذة Edge WebView2 أو المتصفح).

## الاستخدام
1. **الإعدادات**: أضف منتجاتك وخدماتك وأسعارها المعتمدة. الموظف يجاوب منها فقط ولا يخترع أسعاراً.
2. **الموظف الذكي**: الصق المحادثة أو استورد ملف تصدير واتساب `.txt` (من المحادثة: المزيد ← تصدير الدردشة ← بدون وسائط).
3. اضغط **تحليل**، وبيطلع لك الملخص واحتياج العميل والتصنيف وإذا يحتاج تدخل بشري، والرد المقترح وموعد المتابعة.
4. **اعتماد ونسخ**: ينسخ الرد للحافظة، وأنت تلصقه في واتساب وترسله.
5. **⛔ إيقاف فوري**: يوقف كل عمليات الموظف في الحال.

الصفحات: نظرة عامة، صندوق واتساب، العملاء CRM (بحث وتعديل وحذف وإيقاف المتابعة)، الموظف الذكي، مسار المبيعات، الحملات (مسودات فقط)، إدارة المتابعة، التحليلات، الإعدادات، سجل العمليات.

## البيانات والأمان
- كل البيانات محفوظة على جهازك في `data\employee.db` (SQLite)، والسجل في `data\logs\activity.log`.
- يأخذ نسخة احتياطية تلقائياً عند الإغلاق وقبل أي حذف أو ترقية، في `data\backups` (آخر 10 نسخ).
- ما فيه API Key ولا كلمات مرور، وما يقرأ ملفات Cookies، وما يرسل شي لأي خادم.

## للمطورين
```
python -m pytest -q          # الاختبارات (تشمل لقطات شاشة لكل الصفحات في screenshots/)
python main.py --smoke       # اختبار سريع بدون واجهة
```
البنية: `app/web` الواجهة (HTML/CSS/JS مع جسر Python API محلي على 127.0.0.1)، و`app/core` (المحلل، والخدمة، والسجل، وزر الإيقاف)، و`app/db` (قاعدة البيانات والترقيات)، و`app/ai` (المنسق، والمحلل المحلي، ومزود ChatGPT عبر المتصفح)، و`app/automation` (Playwright: واتساب ويب وChatGPT، وكل المحددات في `selectors.py`، فلو تغيّرت واجهة واتساب تعدّلها من هنا)، و`app/core/auto_reply.py` (محرك الرد التلقائي).

## المراحل الجاية
- **V3**: CRM متقدم ومسار مبيعات بالسحب والإفلات.
- **V4**: وضع «موافقة على كل رسالة» داخل واتساب كبديل للرد التلقائي.
- **V5**: المتابعة والحملات للعملاء الموافقين فقط ووفق سياسات واتساب.
- **V6**: اختبارات نهائية ونسخة EXE.

## النسخة 2.0 — برنامج ويندوز كامل، مجاني ومحلي
- **برنامج سطح مكتب**: نافذة خاصة باسم «موظف واتساب» مع أيقونة، وشاشة تحميل، وأيقونة بجنب الساعة (إظهار / خروج)، ومثبّت يحط اختصار في قائمة ابدأ وسطح المكتب. ما يحتاج بايثون عند العميل.
- **واجهة بسيطة**: ٤ أزرار رئيسية (الرئيسية، المحادثات، الطلبات، الإعدادات)، وكل الصفحات الثانية تحت «متقدم». الرئيسية فيها زر واحد كبير يقول لك وش الخطوة الجاية.
- **🌷 عقل المحل المدمج** بدون إنترنت ولا اشتراك: يفهم الطلب والسعر والتوصيل والشكوى، ويطلع المنتج والكمية والموعد والحي والمدينة والجوال (‎+966) والمناسبة. يعرف يوم التأسيس واليوم الوطني والعيدين ورمضان والزواج والتخرج، ويحسب حرارة العميل، ويرد على «غالي» و«بفكر»، ويقترح إضافات. **ما يذكر أي سعر مو موجود في جدول أسعارك (ر.س).**
- **Ollama اختياري** إذا كان شغال عندك أصلاً. **ChatGPT عبر المتصفح تجريبي ومقفل**.
- كل رد ينتظر موافقتك. خارج الدوام تقدر تسمح بالردود الآمنة بس.
- الرسائل الصوتية والصور تروح لـ«يحتاجونك». فحص ذاتي لواتساب ويب أول ما يتصل.
- كرت لكل طلب، وحملات المناسبات (مسودات)، وتذكيرات منبثقة، وتقارير سرعة الرد والتحويل.
- نسخة احتياطية يومية، وتصدير واسترجاع، ومدة الاحتفاظ بالمحادثات.
- **المتصفح**: البرنامج يفتح واتساب ويب بـ Google Chrome إذا موجود، وإلا بـ Microsoft Edge اللي موجود في كل ويندوز 10/11، فما يحتاج تنزيل متصفح.
